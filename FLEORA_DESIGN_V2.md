# Fleora Design V2

Visual redesign based on the approved lavender Fleora mobile reference.

- Light ivory/lavender canvas
- Deep purple primary actions
- Pale lavender secondary surfaces
- Fleora flower wordmark component
- Compact editorial serif headings + clean sans-serif UI text
- Unified thin-line icon system
- Cleaner cards, forms, chips, navigation, and mobile bottom bar
- Existing marketplace, event, vendor, messaging, quote, inspiration, availability, and admin functionality preserved

No new Supabase migration is required for this visual update.
